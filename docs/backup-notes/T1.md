### 设计决策记录

1. **文件变更检测首次运行只建基线不报"全新增"**：避免用户打开启动器时被几百个 Mod 的 Toast 淹没。
2. **面板预览用 `PreviewChanges`，启动通知用 `DetectAndUpdate`**：前者反复看不改基线，后者更新基线后再通知不再重复提醒。
3. **NBT 树结构变化后整树重建**：NBT 文件通常不大，比增量同步更稳。
4. **数据包冲突跳转用 `explorer.exe /select`**：在资源管理器中定位包文件，比文件管理器内建浏览更符合用户习惯。
5. **年度报告 Token 用 Deflate + Base64Url**：完全离线，复制粘贴即可分享，不需要联网或同一份存档。
6. **服务器资源包缓存面板不修改进服的缓存逻辑**：仅可视化现有索引，LRU 淘汰策略由 Core 在进服时自动执行。
7. **ToolboxView 仍为 TabControl 布局**：侧边栏 + 路由改造属于第二梯队，第一梯队仅补面板数量，后续拆 TabItem 到侧边栏即可复用已写的所有 View。
